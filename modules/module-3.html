Fast Triage of Windows Encryption Schemes

What to look for on a live or imaged Windows host in the first hour of response.

Cryptographic subsystems

Subsystem Where it lives Why attackers pick it
Legacy CryptoAPI Advapi32.dll Still seen in older or less-maintained families; well-fingerprinted by defenders
CNG / BCrypt Bcrypt.dll Native to every modern Windows box — no bundled dependency, blends with legitimate app behavior
OpenSSL libcrypto (often statically linked) Cross-platform code reuse between Windows and Linux/ESXi variants
Native Rust / Go ring, aes-gcm, crypto/cipher Single static binary, no DLL import chain to fingerprint, memory-safety for the authors too

Execution & optimization patterns

IOCP & thread pools

A small pool of worker threads services many pending file operations concurrently through I/O Completion Ports, driving very high throughput across drives and shares at once.

Intermittent encryption

Encrypting only headers, or alternating strides (e.g. 1 MB encrypted / 1 MB skipped), renders a file unusable in a fraction of the compute time — and can defeat detection that only samples a file's opening bytes.

Memory-mapped I/O

CreateFileMapping / MapViewOfFile let a file be encrypted in place as addressable memory, skipping per-chunk read/write syscalls — faster, and it leaves fewer discrete API-call artifacts.

Worked example — resource-aware throttling

DeadLock's encryptor (Module 4) runs a dedicated dispatch thread that checks system load before assigning each new file: if memory use climbs past roughly 29% or CPU load passes roughly 70%, new dispatch pauses — while files already mid-encryption are left to finish untouched. The goal is a host that stays responsive enough that nobody notices and reboots it before encryption completes.

Pre-encryption & evasion checklist

Each item below also carries a MITRE ATT&CK technique ID, like T1490. ATT&CK is a free, shared catalog of attacker behavior that security teams use so everyone means the same thing by the same term — a technique ID in your notes means the same thing in someone else's. It's worth learning to recognize a handful of these; they're the closest thing this field has to a common language. See the full framework .

Volume Shadow Copy destruction

T1490

vssadmin delete shadows /all /quiet · Win32_ShadowCopy (WMI/PowerShell) · direct API calls

Event log wiping

T1070.001

wevtutil cl Security/System/Application · EvtClearLog API · WINEVT Channels registry tampering

Security service & EDR termination

T1562.001

Service stop-lists and protected-process termination — and, in some observed intrusions, a BYOVD (T1068, bring-your-own-vulnerable-driver) loader to kill EDR at kernel level.

Language / geofencing checks

T1614.001

GetSystemDefaultUILanguage · GetUserDefaultUILanguage — self-terminates on matched locales; a regional-avoidance signal, not attribution proof
